
# 🛒 Ma Liste de Courses  

Bienvenue sur **Ma Liste de Courses**, une mini-application web développée avec simplicité et efficacité. Elle permet d’ajouter des articles à une liste et de les supprimer facilement. Un petit outil pratique pour apprendre à manipuler le DOM en JavaScript tout en créant un projet utile au quotidien.

---

## 🌟 Objectif du projet  

Ce projet a été conçu pour :

- Offrir une expérience d’ajout/suppression dynamique d’éléments  
- Initier à la création d’une petite application front-end sans framework  
- Proposer un outil utile qu'on peut enrichir ou intégrer à un projet plus vaste  

---

## 💻 Technologies utilisées  

- HTML5  
- JavaScript (vanilla)  
- SASS (pour le style, compilé en CSS)  

---

## 🧠 Fonctionnalités clés  

- Ajout d’articles à une liste via un champ texte  
- Suppression d’un article avec un bouton dédié  
- Ajout possible via bouton **ou** touche *Entrée*  
- Mise au point d’une expérience utilisateur fluide (focus automatique, reset du champ…)  
- Interface simple, facile à personnaliser et responsive  

---

## 🧪 Fonctionnement  

1. L’utilisateur saisit un nom d’article dans le champ texte  
2. Il peut cliquer sur **"Ajouter"** ou appuyer sur *Entrée*  
3. L’article apparaît dans une liste avec un bouton “Supprimer l'article”  
4. Le bouton permet de retirer l’article de la liste  

---

## 🚀 Mise en route  

1. Clone ou télécharge le projet  
2. Ouvre `index.html` dans un navigateur  
3. Commence à utiliser ta liste de courses !  

Aucune installation ou dépendance requise.
